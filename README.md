# Gamer Zone

A small gaming site I built while learning React. Simple games in the browser, with Netlify serverless functions as the backend so I could try full stack without managing a server.

The old Netlify deployment is offline now. The React version aged out, so the app only runs locally these days.

## What I was practicing

Component structure and state, ES6+ syntax, CSS layout, and wiring serverless functions to a React frontend. This was also where I dealt with the differences between React 16 and 17, since the project lived through both.

## Running it

```bash
git clone https://github.com/Ibrahim-Rezq/gamer-zone.git
cd gamer-zone
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

React, JavaScript, CSS, Netlify Functions.
